🎵 MP3 Radio Player

Example of using GitHub-hosted MP3 files with Web Audio API

Audio Player

Ready to load audio

How to Use:

  1. Upload your MP3 file to the audio/ directory in this repository
  2. Get the raw GitHub URL: https://raw.githubusercontent.com/Tedacoder/test-mp3/main/audio/YOUR_FILE.mp3
  3. Enter the URL in the field above
  4. Click "Load Audio" to load the file
  5. Use Play/Pause/Stop buttons to control playback

Alternative: Using HTML5 Audio Element

You can also use a simple HTML5 audio element:

<audio controls>
  <source src="https://raw.githubusercontent.com/Tedacoder/test-mp3/main/audio/YOUR_FILE.mp3" type="audio/mpeg">
</audio>
